# Apply Assist

Chrome extension: open a job application, click **Fill application**, and it
fills the form with your profile, your resume and AI-written answers (Gemini).
Anything it isn't sure about is outlined yellow; required fields it couldn't
fill are outlined red. **It never submits.** You review and click Submit.

## Install (once)

1. Unzip `apply-assist.zip` somewhere permanent (e.g. Documents/apply-assist).
2. Chrome -> `chrome://extensions` -> turn on **Developer mode** (top right).
3. **Load unpacked** -> pick the `apply-assist` folder.
4. Pin it: puzzle-piece icon in the toolbar -> pin **Apply Assist**.
5. Click the icon -> **Settings**: check your details, add phone and GPA,
   upload your resume PDF, paste your Gemini key -> **Save**.

## Use

Open an application page -> click the Apply Assist icon -> **Fill application**.
Watch the box in the bottom-right corner, review the form, then Submit.

Works best on Greenhouse, Lever and Ashby. Workday: sign in yourself, then run
it on each page. Unusual sites: best effort.
